\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

Hardware-in-the-loop (HIL) rigs used to verify battery management systems (BMS) produce high-rate sensor data, but engineers at the industry partner, Analog Devices, currently read that data through raw logs, engineering software and offline scripts.
This slows anomaly detection during long validation runs and makes results hard to present to project leads and customers.
A useful monitoring dashboard must meet three competing needs: connect to a live test platform without disturbing it, show noisy signals without hiding genuine faults, and alert operators without flooding them.

This project designs and evaluates a role-adaptive \emph{digital shadow} dashboard for BMS verification.
It combines a read-only, adapter-based streaming pipeline, a configurable signal-conditioning layer, a four-tier alert hierarchy governed by alarm-management rules, and views tailored to test engineers, project leads and customer demonstrations.
Following Design Science Research, the artefact is evaluated without human participants, through four system-centred experiments on replayed and synthetic traces with seeded faults: pipeline performance, filtering fidelity, alert burden, and an analytical interface evaluation using the Keystroke-Level Model, a visual-clutter metric and a WCAG~2.2 audit.
